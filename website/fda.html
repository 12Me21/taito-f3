TC0650 FDA
“F3 Digital to Analog”

The fda handles color blending and output. for each screen pixel, it reads two rgb colors from color ram (whose address is controlled by the fdp) and some blending info from the fdp (a 4-bit alpha value and a few more bits to control blur, palette mode, additive blending, etc.). it then blends these colors and outputs the result as analog rgb.

The fda also allows the cpu to read and write color ram, with help from the fdp. (i assume it just connects the cpu data bus to color ram data, when instructed to by the fdp or fcm)
